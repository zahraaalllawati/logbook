# PICU Logbook

The residents' procedure log for PICU and HDU, Sultan Qaboos University Hospital.

This page holds no names and no entries. It signs residents in by email and talks to a Google Apps
Script, which keeps the entries in a Google Sheet. Open it on a phone and add it to the home screen.
